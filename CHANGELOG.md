# Changelog

## 2.0.0

- Rewritten from scratch. The three editions are now the same plugin with different starting options; every option can be changed in Settings > Plugins.
- Unlock hides by checking which program MO2 is waiting on, so "game only" works for any game MO2 manages and its script extender (SKSE, F4SE...). xEdit and other tools keep their Unlock button.
- Biggie Edition now hides all three bulk Delete Downloads entries, not just Installed.
- No more constant window scanning and no debug file written to a hardcoded folder (thanks ellisalgernon).
- Uses MO2's own widget names and translations, so it no longer matches on English button text.
